Diberikan sebuah array integers `nums` dan integer `target`, kembalikan indeks pengembalian dari 2 angka yang jika di tambah itu sama dengan nilai `target`

Example 1
- Input: nums = [2,7,11,15], target = 9
- Output: [0, 1]
- Explanation -> Beacuse nums[0] + nums[1] == 9, we return [0, 1]
