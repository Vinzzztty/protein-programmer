## Problem summary

- Tulis ulang soal ini dengan bahasamu sendiri.
- Catat input, output, constraint, dan contoh penting.

Diberikan sebuah cycle linked list yang dimana node list itu bisa reached again berkelanjutan diikutin `next` pointer. Adapun varible `pos` yang digunakan untuk menunjukkan varibale index `next` yang terhubung dari `tail`.

Note:
- `pos` tidak dilewatkan sebagai parameter
- Return `true` jika terdapat dalam siklus linked list, jika sebalikanya return `false`
